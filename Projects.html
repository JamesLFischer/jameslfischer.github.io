Infrastructure Project 2026

Redacted verification capture · one VM after its upgrade

Linux · VMware ESXi · Automation

Radmin Fleet Migration

An in-place operating-system migration for the Radmin fleet, Linux virtual machines on VMware ESXi, moving them off end-of-life CentOS 7 to AlmaLinux 8.10.

Problem
A 146-VM fleet was still on CentOS 7 after it reached end of life.
Built
Python (paramiko) and PowerShell tooling that scans the network, finds fleet VMs, and pushes updates in parallel, with staged test VMs and batch queues running 4 concurrent workers.
Verified
A post-upgrade gate on each VM checks the OS release, kernel, firewall policy, and required services before it is marked done.
Outcome
Most of the fleet now runs AlmaLinux 8.10, with every upgrade logged and verified per VM.
  • Python
  • PowerShell
  • Bash
  • AlmaLinux
  • VMware ESXi
  • SSH
146VMs in the fleet

70VMs standardized in batches of 10, zero unresolved failures

ComfyUI · Python · FFmpeg

Skull World: VHS Render Pipeline

A local pipeline that makes VHS-style footage for Skull World, a game I’m building. Custom SDXL LoRA trained on about 4,000 frames from my own VHS and art datasets, ComfyUI with ControlNet for character consistency, Python-scripted camera and character animation, a custom animated VHS filter piped into ffmpeg, and an ownership watermark baked in before the tape filter. Runs on a laptop GPU with 8 GB of VRAM.
